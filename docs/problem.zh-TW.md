# 問題敘述

[English version](problem.md)

為 3×3 slot game 設計一組 reel strip，使其達到指定的回報率與最低中獎頻率。

## 遊戲設定

- **盤面**：3 欄 × 3 列，每一欄由一條獨立的 reel 提供。
- **Reel**：共 3 條。各條長度可以不同，且沒有長度上限。可以把每條 reel 想像成一個大型轉筒。
- **符號**：共 5 種，各有對應的 payout 倍率：

| 符號 | 倍率 |
|---|---|
| 0 | 0.25 |
| 1 | 0.55 |
| 2 | 1 |
| 3 | 3 |
| 4 | 5 |

## Payout 規則

| 型態 | Payout |
|---|---|
| A、B、C、D | 押注 × 符號倍率 |
| E | 押注 × 符號倍率 × 5 |

## 設計目標

1. **RTP = 0.95**：玩家每押 100 單位，期望拿回 95 單位。
2. **勝率 ≥ 55%**：至少 55% 的 spin 必須中獎。

## 交付內容

任何一組同時滿足以上兩個目標的 reel 配置，並附上證明它確實符合的依據。

規則中未明確說明的地方（例如多個型態重疊時如何計算 payout、「中獎」如何定義），統一在 README 的[假設](../README.zh-TW.md#假設)一節中處理。
