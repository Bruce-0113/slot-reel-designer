# Slot Game 入門

[English version](slot-game-primer.md)

本文介紹這個專案用到的 slot game 概念，只涵蓋理解 reel 設計問題所需的內容，不是博弈遊戲的完整指南。

---

## 1. Slot Game 的基本結構

### Reel 與 reel strip

**Reel（滾輪）** 是一條循環的符號序列，可以想像成貼在轉筒上的一長條紙帶。在程式裡，它就是一個頭尾相接的 array。

```
Reel strip（長度 8）:  [0, 0, 1, 0, 3, 0, 2, 4]
                        ↑ index 0            ↑ index 7 → 接回 index 0
```

**Reel strip** 是每條 reel 上完整的符號排列，也是 slot game 最主要的設計變數。

### Stop 與盤面

每次 spin，每條 reel 各自隨機停在一個位置，稱為 **stop**，每個位置的機率相同。玩家看到的 **盤面（window）**，是從 stop 開始往下連續的幾個符號。

```
Reel strip:  [0, 0, 1, 0, 3, 0, 2, 4]
Stop = 6  →  盤面顯示 index 6、7、0  →  (2, 4, 0)
```

3×3 的遊戲使用三條 reel，每條 reel 提供盤面的一 **欄**：

```
          Reel 1    Reel 2    Reel 3
第 1 列 │  r1[s1]    r2[s2]    r3[s3]   │
第 2 列 │  r1[s1+1]  r2[s2+1]  r3[s3+1] │
第 3 列 │  r1[s1+2]  r2[s2+2]  r3[s3+2] │
```

由此得出兩個結構性質，它們決定了整個設計方式：

- **不同欄互相獨立**：每條 reel 各自獨立停止。
- **同一欄的各列彼此相關**：它們是同一條 strip 上 *相鄰* 的符號，不是各自獨立抽出來的。

因此 3×3 盤面 **不是** 9 個獨立的隨機符號。若要讓同一欄上下相鄰的格子相同，設計者必須把相同符號放在 strip 上相鄰的位置。

### 結果空間

若三條 reel 長度分別為 L₁、L₂、L₃，總共有 **N = L₁ × L₂ × L₃** 種機率相同的結果。遊戲中所有機率都是分母為 N 的分數，所以每個指標都能用窮舉 **精確** 算出，而不只是用模擬估計。

## 2. 中獎規則

| 名詞 | 意義 |
|---|---|
| **Payline / 中獎型態** | 一組預先定義的格子；這些格子全部是同一符號時，該次 spin 中獎。 |
| **Paytable（賠率表）** | 每個符號的倍率。越稀有的符號通常倍率越高。 |
| **Payout** | `押注 × 倍率`，有時會再乘上額外係數，例如全盤中獎 ×5。 |
| **多線計算** | 一次 spin 同時中多個型態時，多數遊戲會把各型態的 payout **加總**。 |

其他常見機制（本專案未使用）：*ways-to-win*（如 243 ways）、wild、scatter、免費遊戲、倍數加成。

---

## 3. 核心指標

### RTP（Return to Player，回報率）

長期下來，每押 1 單位平均能拿回多少：

```
RTP = E[payout] / 押注
```

RTP 0.95 代表玩家押 100 單位，平均拿回 95 單位。商業遊戲常見數值為 0.92–0.97，許多地區的法規會訂下限。

### House edge（莊家優勢）

`1 − RTP`。RTP 0.95 時，營運方長期保留總押注的 5%。

### Hit frequency（勝率）

一次 spin 有任何 payout 的機率：

```
Hit frequency = P(payout > 0)
```

### Volatility（波動度）

每次 spin payout 的變異數或標準差。

- **低波動**：常中小獎。
- **高波動**：很少中，但一中就是大獎。

### RTP 與勝率的關係

兩者是彼此獨立的設計維度：

| | 低勝率 | 高勝率 |
|---|---|---|
| **相同 RTP** | 少見的大獎 | 頻繁的小獎 |

只要大部分獎項金額都小，遊戲就能同時有高勝率和適中的 RTP。

## 4. 中獎但虧錢（Losses Disguised as Wins, LDW）

payout 低於押注的獎項，畫面上仍會顯示為「中獎」：

```
押 1 → 符號倍率 0.25 → payout 0.25 → 淨結果 −0.75
```

倍率低於 1 的符號，是業界用來便宜地拉高勝率的常見手法。這也影響「勝率」要怎麼解讀，它可能指：

- `P(payout > 0)`：只要有 payout 就算中獎，**或**
- `P(payout > 押注)`：只有淨賺才算中獎。

## 5. 設計者如何調整遊戲

主要的調整手段：

1. **Reel 長度**：越長的 reel，機率能調得越細。
2. **符號頻率**：每個符號在每條 reel 上出現幾次。
3. **符號擺放**：把相同符號集中排列（*stacking*），讓上下相同更容易發生。
4. **各 reel 不對稱**：reel 不必相同。例如可以讓高倍符號在中間 reel 上很少出現，限制它連成型態的頻率。

設計結果會整理成 **PAR sheet**（Probability Accounting Report）：列出每種中獎組合的機率、payout，以及對 RTP 的貢獻。遊戲上市前，主管機關會審閱這份文件。

兩個相關概念：

- **RNG（亂數產生器）**：決定每條 reel 的 stop，必須經過認證、不可預測。
- **Virtual reel（虛擬滾輪）**：實體機台會把少數實體位置映射到大量虛擬位置，藉此塑造機率。設計問題中「reel 長度不限」扮演的就是相同角色。

## 6. 對應到本專案

| 專案需求 | 對應的 slot game 概念 |
|---|---|
| 3 條 reel、3×3 盤面 | Reel strip + 盤面 |
| 5 種中獎型態（4 個 2×2 方塊 + 全盤） | 自訂 payline |
| 符號倍率 `{0: 0.25, 1: 0.55, 2: 1, 3: 3, 4: 5}` | Paytable |
| 全盤 payout × 5 | 額外倍數 |
| RTP = 0.95 | 主要設計目標 |
| 勝率 ≥ 55% | Hit frequency 限制（低倍率符號有幫助，見 LDW） |
| Reel 長度不限 | 用來精確達成 RTP 的設計自由度 |

簡單來說，目標是設計三條 reel strip，相當於一份迷你 PAR sheet，讓遊戲精確達到指定 RTP 和最低勝率，並用精確計算與模擬兩種方式驗證。
