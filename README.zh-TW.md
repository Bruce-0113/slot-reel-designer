# slot-reel-designer

[English](README.md) | 繁體中文

為 3×3 slot game 設計 reel strip，使 **RTP 精確等於 0.95**，且 **勝率（hit frequency）不低於 55%**，並以完整窮舉與 Monte Carlo 模擬驗證結果。

> 不熟悉 slot game？請先閱讀 [Slot Game 入門](docs/slot-game-primer.zh-TW.md)。

## 問題定義

- 3×3 盤面、3 條 reel（各條長度可不同，無長度上限）
- 5 種符號，倍率為 `{0: 0.25, 1: 0.55, 2: 1, 3: 3, 4: 5}`
- 5 種中獎型態：4 個 2×2 方塊（payout = `押注 × 倍率`），以及全盤（payout = `押注 × 倍率 × 5`）
- 目標：**RTP = 0.95**，且 **勝率 ≥ 55%**

完整敘述：[`docs/problem.zh-TW.md`](docs/problem.zh-TW.md)

## 假設

1. 每條 reel 以相同機率停在任一位置，各 reel 互相獨立；盤面顯示連續 3 個符號（頭尾相接）。
2. 一次 spin 同時符合多個型態時，各型態的 payout **加總**。
3. 全盤中獎時，4 個 2×2 型態也同時成立。主要交付成果讓 5 個型態全部派彩（**`sum_all`**：4 × 倍率 + 5 × 倍率 = 9 × 倍率，與假設 2 一致）：[`configs/reels.json`](configs/reels.json)。另一種解讀（**`full_only`**：全盤只派 5 × 倍率）的配置也一併提供於 [`configs/reels_full_only.json`](configs/reels_full_only.json)。
4. 「中獎」定義為 `payout > 0`；同時另外報告 `payout > 押注` 定義下的結果。
5. 每次 spin 押注 1 單位；RTP = E[payout] / 押注。

## 設計要求

上述目標只規定了 RTP 與勝率。為了讓結果像一款真正的遊戲，最終配置依下列要求設計（詳見 [`docs/methodology.zh-TW.md`](docs/methodology.zh-TW.md#1-符號與要求)）：

- **必要條件**（精確檢查）：H1 在該設定檔的 payout 模式下 RTP 精確等於 19/20 · H2 勝率 ≥ 11/20 · H3 每個符號都對 RTP 有貢獻 · H4 每個型態都有機會中獎 · H5 每條 reel 都包含全部 5 種符號。
- **偏好**（依優先順序）：S1 倍率越高的符號，spin 在該符號中獎的機率越低 · S2 每個符號都可能出現全盤 · S3 勝率落在 [0.55, 0.70] · S4 每條 reel 最多 150 個符號。

## 結果

兩組配置都精確滿足 H1–H5。精確值以分數涵蓋全部 stop 組合算出；模擬值來自 `python -m slot_reel_designer.verify`（n = 10⁷ 次 spin，種子 0），以「估計值 ± 95% 信賴區間半寬（1.96 個標準誤）」表示。

## 方法

1. **先做概念驗證**：一組刻意簡化的 reel 家族精確達到 RTP = 19/20，並把整條流程跑過一遍（[`docs/poc.md`](docs/poc.md)，英文）；它的缺點（所有中獎都在符號 0、勝率 96%）促成了上面的設計要求。
2. **精確評估**：每條 reel 先化簡成各種不同盤面欄位的出現次數，與中間欄組不成 2×2 方塊的外側欄再合併成一個空白欄，因此最多只需計分 125 × 10 × 10 個盤面，就能涵蓋全部 L₁·L₂·L₃ 種停止位置組合。所有運算都使用 `fractions.Fraction`，RTP 是否相等以精確分數判斷，不受浮點誤差影響。
3. **計數模型**：所有統計結果只取決於每條 reel 的長度，以及每個符號在循環 strip 上的成對數與三連數（每條 reel 16 種狀態、共 4,096 種狀態組合），與 strip 的排列方式無關。20·L₁·L₂·L₃·RTP 必為整數，所以「RTP = 19/20」只是整數運算。
4. **搜尋配置**：以設定種子的模擬退火（10 次，每次 60,000 步）在連續區段計數上最小化一個依要求優先順序設計的懲罰函數。接著以精確收尾讓 RTP 剛好等於 19/20：固定兩條 reel 時，整數化的 RTP 超出量是第三條 reel 區段計數的仿射函數，因此用中間相遇法列舉，就能找到讓超出量歸零的計數。
5. **建構 strip**：把選中的區段計數排列成 strip，使同一符號的連續區段永不相鄰，再以精確評估器重新檢查建好的 strip。
6. **驗證**：精確窮舉、暴力窮舉交叉驗證、附 95% 信賴區間的 Monte Carlo 模擬，以及 2,490 個測試。

詳細說明：[`docs/methodology.zh-TW.md`](docs/methodology.zh-TW.md)

## 快速開始

需要 Python 3.10 以上版本。

```bash
python -m venv .venv
source .venv/bin/activate                 # Windows：.venv\Scripts\activate
pip install -r requirements.txt

python -m slot_reel_designer.solve        # 搜尋兩種 payout 模式並重寫 configs/*.json（約 45 秒）
python -m slot_reel_designer.verify       # 精確驗證（H1–H5）+ 每個設定檔 10^7 次 spin 的 Monte Carlo 模擬
python -m slot_reel_designer.report       # 重新產生 docs/par-sheet.md 與 docs/par-sheet.zh-TW.md
pytest                                    # 快速測試：2,483 個，只需幾秒
pytest -m slow                            # 7 個較慢的檢查：重跑搜尋、暴力窮舉（需要幾分鐘）
```

- `solve` 可指定 `--mode sum_all|full_only|both`、`--seed N` 與 `--out-dir DIR`。使用預設參數時，會逐位元組重現已提交的設定檔。
- `verify` 可指定 `--config PATH ...`、`--n SPINS` 與 `--seed N`。若設定檔違反 H1–H5，或模擬結果與精確值相差超過 4 個標準誤，結束代碼為 1。
- `python -m slot_reel_designer.poc` 會重跑概念驗證的掃描，並儲存 `configs/poc_reels.json`。
